# C++ Modules

A collection of **C++ learning modules** (CPP00-CPP09) covering Object-Oriented Programming, memory management, templates, and STL.

## Modules Overview

| Module | Topic | Key Concepts |
|--------|-------|--------------|
| **CPP00** | Namespaces & Classes | Classes, member functions, constructors |
| **CPP01** | Memory & References | `new`/`delete`, pointers, references |
| **CPP02** | Operator Overloading | `+`, `-`, `<<`, `>>`, const correctness |
| **CPP03** | Inheritance | Base/derived classes, hierarchies |
| **CPP04** | Virtual Functions | Polymorphism, abstract base classes |
| **CPP05** | Exceptions | `try`/`catch`/`throw`, error handling |
| **CPP06** | Type Casting | `static_cast`, `dynamic_cast`, `reinterpret_cast` |
| **CPP07** | Templates | Function & class templates, specialization |
| **CPP08** | STL Basics | Containers, iterators, algorithms |
| **CPP09** | STL Containers | `vector`, `list`, `map`, `set` |

## Quick Start

```bash
cd CPP00
make
./program_name
```

## Compilation

```bash
# With C++98 (default for 42 school)
g++ -std=c++98 -Wall -Wextra -Werror *.cpp -o program

# With C++11+
g++ -std=c++11 -Wall -Wextra -Werror *.cpp -o program
```

## Key Concepts

- **OOP**: Classes, inheritance, polymorphism
- **Memory**: Stack/heap allocation, RAII pattern
- **Generics**: Templates for reusable code
- **STL**: Containers and algorithms
- **Exceptions**: Error handling and safety

## Learning Path

**Beginner** → CPP00, CPP01, CPP02  
**Intermediate** → CPP03, CPP04, CPP05  
**Advanced** → CPP06, CPP07, CPP08, CPP09
